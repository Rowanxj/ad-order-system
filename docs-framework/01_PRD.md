# 广告制作公司宣传物料订单管理系统 · 产品需求文档

## 1. 背景与目标

广告制作公司接到客户委托后，由客户经理登记订单，业务负责人确认并分派，设计制作人员出稿，客户经理把客户意见与确认结果记回系统，全部物料确认后由负责人交付。

要解决的问题：一笔订单跨 3 个岗位、多轮修改，**谁改了什么、谁确认了哪一版、还差什么没交**说不清。口头传达 + 微信传图导致返工与扯皮。

成功指标：

- 任一物料能从登记追溯到交付，每个关键动作可查到操作人、角色、时间；
- 越权操作 100% 被服务端拦截（不依赖前端隐藏按钮）；
- 客户确认与设计上传在数据上明确区分，不存在"传了就算确认"。

## 2. 术语

| 术语 | 定义 | 易混淆点 |
| --- | --- | --- |
| 物料订单 | 客户的一次委托，含一项或多项物料 | 不是"一笔物料" |
| 物料任务 | 订单下的一项具体物料（海报/展架/菜单/宣传册/线上配图） | 与订单是 1:N |
| 设计版本 | 某个任务的一次投稿文件 | 只追加不覆盖，版本号递增 |
| 上传 | 设计人员提交一版文件 | **不等于**确认 |
| 客户确认 | 客户认可当前版本 | 只能由客户经理记录 |
| 变更记录 | 订单确认后对要求/时间的修改 | 不是修改原记录，是追加一条 |
| 待分派 / 待开始 | 任务 `PENDING` 状态的两种处境：没有分派人 / 已有分派人但尚未开始设计 | 状态码相同，展示时必须区分 |

## 3. 角色与权限

| 角色 | 代码 | 核心诉求 | 数据可见范围 |
| --- | --- | --- | --- |
| 客户经理 | SALES | 把客户要求准确记进系统 | 全部订单与客户 |
| 业务负责人 | MANAGER | 排产、分派、按时交付 | 全部订单与任务 |
| 设计制作人员 | DESIGNER | 清楚今天做哪几项、改哪一版 | **仅有自己任务的订单与任务** |

关键边界（服务端强制）：

- 设计人员访问无关订单/任务 → 403；
- 设计人员操作他人任务 → 403；
- 设计人员不能确认订单、不能记录客户确认；
- 客户经理不能确认订单、不能分派；负责人不能记录客户确认。

## 5. 页面元素（逐页）

### 5.1 登录 /login

- 区块：标题、账号、密码、登录按钮、演示账号快捷填充
- 交互：提交 → 成功存 token 与用户信息 → 跳转工作台
- 状态：提交中按钮 `loading` 且禁用
- 异常：账号或密码错误 → 顶部消息显示后端 message；网络失败 → "网络错误"

### 5.2 订单列表 /orders

- 区块：标题区（标题 + "共 N 笔订单" + 新建按钮）、筛选区（状态、客户、关键词、设计人员、只看逾期）、表格、分页器、空态
- 表格列：订单号、标题、客户、状态标签、物料进度 `n/m`、截止日期、创建人、操作
- 分页：默认每页 10 条，可选 10/20/50；筛选条件变化时回到第 1 页
- 交互：点行进详情；筛选变化即查询
- 状态：加载中 `v-loading`；无数据 `el-empty`
- 异常：401 由拦截器统一跳登录

### 5.3 新建订单 /orders/new

- 区块：客户选择、订单标题、需求说明、整体截止日期、物料明细动态行（类型/名称/规格/数量/用途/参考/截止日期）、增删行按钮
- 校验：客户必选、标题必填、至少 1 项物料、数量 ≥ 1
- 交互：提交成功 → 跳订单详情
- 异常：校验失败前端提示；后端 400 显示 message

### 5.4 订单详情 /orders/:id

- 区块：订单头（编号/标题/状态标签/截止日期）、客户卡片、需求说明、任务表、操作历史时间线
- 按角色显示操作按钮：
  - 负责人：确认订单、交付订单、分派任务
  - 客户经理：取消订单、修改截止日期、新增物料
  - 任务行内：设计人员（本人）开始设计/上传；客户经理记录意见/确认/改期
- 状态：加载中骨架或 `v-loading`；无任务、无历史 → `el-empty`
- 异常：403 提示无权限且不渲染数据；409 提示当前状态原因并刷新

### 5.5 任务详情 /tasks/:id

- 区块：任务信息、所属订单上下文、版本时间线（版本号/文件名/大小/提交说明/时间/下载）、客户意见列表（轮次/内容/记录人/时间）、操作区
- 交互：下载设计稿带 token（blob）；上传需选择文件 + 可选说明
- 状态：无版本、无意见 → `el-empty`
- 异常：文件不存在 → 提示并保留列表

### 5.6 我的设计任务 /my-tasks

- 区块：状态筛选、任务卡片/表格（来自哪笔订单、物料名、状态、截止日期）
- 交互：点进任务详情
- 状态：无任务 → `el-empty`

### 5.7 任务工作台 /tasks

- 区块：标题区（共 N 项任务）、筛选区（关键词、状态、分派人、订单、仅看逾期、仅看未分派）、任务表、分页器、空态
- 表格列：任务、所属订单、客户、分派人、状态、截止日期（逾期高亮）、版本/意见、操作（详情/分派）
- 交互：筛选变化回到第 1 页；负责人可对「待分派 / 待开始」任务直接分派或改派
- 状态：加载中 `v-loading`；无数据 `el-empty`
- 异常：403 由路由守卫拦截（仅负责人菜单可见）

### 5.8 客户管理 /customers

- 区块：搜索框、表格（名称/联系人/电话/行业/备注/登记人）、新增弹窗
- 交互：新增成功刷新列表
- 状态：无数据 `el-empty`

### 5.9 工作台 /dashboard

- 区块：角色指标卡（待确认/待分派/待客户确认/逾期/进行中/已交付）、优先处理任务、逾期订单、快捷入口
- 交互：点指标卡跳到订单/任务工作台或异常管理；点任务/订单进入详情
- 状态：加载中 `v-loading`；无数据 `el-empty`

### 5.10 异常管理 /exceptions

- 区块：异常类型切换（逾期/待分派/待确认/已延期/可交付）、关键词、左侧异常列表 + 右侧处理详情、分页
- 交互：负责人可直接分派/改期；客户经理可记录客户确认/修改意见
- 状态：无异常 `el-empty`
- 异常：403 由路由守卫拦截（SALES/MANAGER 专属）

以上 10 个页面 + 负责人专属的账号管理页即全部界面，无其他入口。

## 6. 非功能需求

| 类别 | 要求 | 落的点 |
| --- | --- | --- |
| 一致性 | 状态冲突返回 409 且消息带当前状态 | `OrderService.checkTransition` |
| 安全 | 越权 403；文件下载防穿越且校验数据归属；密码不落日志、不出 JSON | 拦截器 + `requireAssignee` + `resolve(viewer, path)` + `@JsonIgnore` |
| 可追溯 | 关键动作写 `operation_log`，含操作人角色 | 12 个动作码 |
| 体验 | 提交防重复、统一消息、空态齐全 | 前端各页 |
| 性能 | 列表 P95 < 500ms（演示量级） | 索引 `idx_status`、`idx_assignee` |
| 兼容 | Chromium 内核浏览器，1440×900 以上 | Element Plus 默认布局 |

## 7. 明确不做（V2 及以后）

- 客户列表与"我的任务"分页（数据量小，全量返回）；订单列表已支持分页；
- 消息通知与待办提醒；
- 设计稿在线批注；
- 对象存储与多实例部署；
- 客户自助下单。
